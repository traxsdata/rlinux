# Paths deliberately removed from rlinux (issue #5, "Diet", phase A).
#
# rlinux is an incremental C-to-Rust kernel port: a Rust module can only be
# built for an architecture that selects HAVE_RUST.  The 13 architectures in
# this list (plus their arch-only buses/drivers, sound boards and docs)
# cannot build Rust at all, so a driver converted to Rust can never compile
# or run there.  They were removed to cut ~1M lines of dead weight that
# costs review time and tree size.
#
# Supported architectures (the ones that select HAVE_RUST):
#   x86, arm, arm64, riscv, loongarch, powerpc, s390, um
#
# Syncing with upstream: when a future sync imports paths that were
# removed here, resolve the modify/delete conflicts by re-deleting them
# with:
#   xargs git rm -r -q < scripts/rlinux/pruned-paths.txt
#
# The list is authoritative: anything under a path below stays deleted.
